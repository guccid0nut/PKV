## [5.0.2] — War Effort Quests, Matchmaking & Clan Fixes, Queue Arcade Slot Swaps, Custom Map Stats & CLI Updates

> 📖 Full player & operator notes: [`docs/releases/v5-update-notes.md`](docs/releases/v5-update-notes.md) • [`docs/releases/whats-new-in-v5.md`](docs/releases/whats-new-in-v5.md)

### Added
- **War Effort Quest & Reward Track *(Initial Rollout)*:** Replaced the unused `HON LIVE` homepage midbar slot with **War Effort** (Replays remain in the System Bar), backed by a 28-day cycle service (`WarEffortService` + `WarEffortProgressionService`), `2` daily quest slots (`00:00 UTC` refresh, up to `2` banked rerolls), incremental quest progress counts (`0/1`, `10/10`), faction-neutral melee/ranged & role icons (`role_carry`), classic + custom map objectives (`Strikers`, `10v10`, wards, assists, building damage), `14` Merrick milestone bags/chests (Silver, Gold, Plinko Tickets, `Dragon's Treasure Ward`, `Gnome Courier`), basic anti-farm match checks, a War Effort Leaderboard (`GetLadder('quests')`), and a `WarEffort:Enabled` server toggle.
- **Custom Map Stats, Match History & Scoreboards:** Added custom stat ingestion, match history persistence/display, `arena_Hero_*` base hero portrait/name lookup, custom-row MVP icons, and mode-specific scoreboards across `Strikers`, `10v10`, `Devo Wars`, `HoN Arena`, `Prophets`, `Team Deathmatch`, duel-life maps, and co-op modes.
- **Queue Arcade Human ↔ Bot Slot Swaps:** Added Windows (`version.dll`) and Linux (`libkongor_native_guard.so`) slot-handoff hooks (`GenerateClientID`, `SpawnHero`, `Terminate`, `Disconnected`, `AttachBot`) with `ArcadeSlotOrigin[32]` tracking, mid-match `BotBrainCore` hero rebinding, `BotReadiness` acks, `kongor_arcade_swap_hooks` / `KONGOR_ARCADE_SWAP_HOOKS` kill-switches, and `[Queue Arcade]` takeover/return chat notices when players join or leave active skirmishes.
- **Global `kongor` CLI Workspace Resolution & Shell Completions:** Updated `kongor` so commands resolve a registered checkout or playtest bundle from any directory (`KongorWorkspaceResolver`, `~/.kongor/config.json`, `kongor where`, `kongor workspace`), added a lightweight `~/.kongor/bin/kongor` forwarder shim and shadow-slot launcher to avoid rebuild file locks, ported remaining `kongor.ps1` developer subcommands, scoped `kongor stop`/`clean` to the active workspace, and added static shell tab-completions (`powershell`, `bash`, `zsh`, `fish`).
- **Control Panel Launcher Sync & Server Chat Console:** Added Named Pipe endpoint sync (`CockpitAppBridgeService`) between `NEXUS.ControlPanel.GUI` and a running `WILLOWMAKER` window, plus an embedded/pop-out dedicated server chat & command console (`GameServerChatConsoleControl` / `GameServerChatPopOutWindow`) backed by `COMPEL`.
- **High-Hz DirectFlip Pacing, Implicit Vulkan Layer Shield & Cross-PC VRR Readiness (`HZ-01..07`, `UX-01..04`):** Gated `VkLayer_hon_replay_capture.dll` strictly behind explicit capture / Modern HUD modes (`HON_CAPTURE_DISABLE=1`) plus an explicit `HON_RENDERDOC_ENABLE=1` opt-in guard (`DISABLE_VULKAN_RENDERDOC_CAPTURE` respected) so `renderdoc.dll` never injects unrequested; added a shared `VulkanImplicitLayerShield` in `Kongor.Core` (wired into `WILLOWMAKER` and `kongor-cli`) that discovers host `HKLM`/`HKCU` Khronos `ImplicitLayers` manifests and neutralizes third-party hooks (`OBS`, `SteamOverlay`, `SteamFossilize`, `RenderDoc`, `MediaSDK`) via each manifest's `disable_environment` key; tuned DXVK `maxFrameLatency=2` / `dxvk.latencySleep=False`; added `vid_vulkan_x64.dll` fast-bus `frameDraws` telemetry and SHJ `runtime-audit` (`I7`) / `perf-canary` (`I5`) verification; promoted Graphics Quality & Shadow Fidelity (`High (2048)` default) and `Off (Clean Screen)` HUD default with `SettingsSchemaVersion = 2` migration, active preset diff banner, vendor-neutral EDID + DXGI/OS VRR readiness detection (`DisplayVrrDetectionService`), 1-click sub-refresh VRR FPS cap helper, and secret-redacted `LaunchReceiptService` launch receipts with deterministic `willowmaker.buildinfo.json` binary freshness checks.
- **Offline & DirectPlay P2P "Select a Mode" & Store Guards:** Greyed out and locked online-only matchmaking banners (**Ranked**, **Quickmatch**, **Mid Wars**) and **Regions** with `OFFLINE` pills and hover guidance in Offline Hub and DirectPlay P2P while keeping **Bot Match** and **Public** open for local/custom practice, and greyed out/guarded the main-menu **Store** button (and MOTD `VISIT STORE`) with a Hero Pick skins tooltip while offline—automatically restoring full-color animated access on online login (verified on Windows Vulkan and Linux OpenGL, both `large` and `small` UI).
- **Playtest Release Drop Folder Automation:** Enhanced `scripts/release/export_playtest_bundle.ps1` to auto-stage an upload-ready `release/` drop folder alongside the unpacked bundle containing the compressed `.zip`, `.zip.sha256`, full-folder `SHA256SUMS.txt`, `README.txt`, `RELEASE_NOTES_v5.0.2.md`, `CHANGELOG.md`, `LICENSE`, `LICENSE.native-mpl2.txt`, `NOTICE`, `THIRD_PARTY_NOTICES.md`, `CREDITS.md`, and `AI_GRATITUDE.md`.
- **Experimental Voice Denoising, P2P Relays & Platform Scaffolding:** Added experimental `RNNoise` voice chat noise suppression and P2P STUN/relay NAT helpers, alongside early Linux Zink/Wayland adjustments and initial `ReplayStudio`, Garage CAS, and XDP scaffolding.

### Fixed & Improved
- **WILLOWMAKER Mod Manager Consolidation & Shutdown-Hang Sentinel Hardening:** Hid the legacy standalone `Mod Manager` button in `WILLOWMAKER` (all mods are now managed directly in-game under **Options -> Mods**), routed diagnostic crash acknowledgment canonically to `userdataKONGOR/launcher_settings.json` with high-water-mark migration, added clean-exit correlation against `player_sessions.jsonl` to prevent PID-reuse false positives, and eliminated false-positive `0xCFFFFFFF SHUTDOWN_HANG_TIMEOUT` banners on clean quits.
- **Valkey Matchmaking & Unique Clan Names/Tags:** Fixed a Valkey/Garnet script and queue-state bug in `TRANSMUTANSTEIN.ChatServer` that could stall matchmaking pairing (verified under a 4-pod `2,500`-player live Valkey 8.1 atomic Lua load proof + `5,000`-caller single-flight population stampede proof in [`docs/benchmarks/v502_backend_load_proof.md`](docs/benchmarks/v502_backend_load_proof.md)), and added case-insensitive functional `lower()` unique indexes for Clan Tags and Clan Names in `MERRICK`.
- **Custom Map Lobby Checks, Practice Seeding, Shops & Kickoff Timing:** Added lobby team-count warnings on life- and round-based custom maps (`Pebbles Duel`, `Colosseum Duel`, `Empath Maze`, `True Devo Wars`, `HoN Arena`) with optional practice bot/`FakePlayer` seeding; defaulted `True Devo Wars` `B` (`ToggleShop`) to `Shop_Outpost` with unused Caldavar tabs hidden; added an opening shared-lives tip, solo-start, 5 Hellbourne slots, 8-hero roster, and 60s pick timer in `Nightmarish Co-Op`; fixed bronze medallions, 9-slot Spellbringer bar, and 8-pedestal inspector in `Enfo's Team Survival`; fixed `720p` War Effort layout scaling and Linux `Data/wareffort` path casing; and fixed duplicate post-goal `3-2-1` countdowns in `Strikers`.
- **Offline & Online In-Game Shop Guides & Featured Guide Purchasing:** Normalized hero item guides across Mid Wars and all classic/custom maps in both Offline and Online modes so featured and default guides load cleanly and purchase items directly without having to leave the guide view.
- **10v10 Local Bot Phase-Staggering, Combat-Bounded `AssetPrewarmer` & Override Cleanup:** Desynchronized local bot brain assessment ticks across deterministic phase slots with out-of-combat perception scaling in `>= 12`-hero (`10v10`) local matches (preserving instant combat response); upgraded `AssetPrewarmer` (`v2.0.0`) to skip standard shop prewarming on custom/shop-less maps (`Strikers`, `Devo Wars`, arenas), adapt `gated`/Reborn items, cover `ScoreboardPlayer0..19`, and hard-stop prewarming at the `0:00` combat horn so zero synchronous `.effect` disk loads hitch mid-fight; and fixed parse-time `purchase_confirmation_*` triggers, `tarot` duplicate state registration, and bounded `svr_proxyPort`/`man_startServerPort` defaults.
- **20-Player (`10v10`) Kill Packets & Bot Script Fixes *(Early AI)*:** Expanded hero-kill packets (`0x44` / `0x6B` / `0x60`) from 28 B to 128 B on Windows and Linux (`kill5`..`kill10` stringtables); added basic arena/maze patrol points in `Colosseum Duel` and `Empath Maze`; and synced missing VFS ability/item state bindings (`bots/core.lua`, `bots/botbraincore.lua`) to reduce bot Lua warning spam.
- **Avatar Visuals & Hero Pick `<modelpanel>` Cleanup:** Grounded `Hero_Devourer` (`Base`, `pog_skin`, `Alt12`, `Alt15`) blood decals in Store/in-game while hiding floor decals on Hero Pick; fixed duplicate Store models on `Hero_Bubbles.trophy_skin` (`Basic` & `Elite`); and cleaned up `Hero_Xalynx.alt_eucliwoodhellscythe` effect handles during `ui:lobby_avatars` teardown.
- **D3D9 UI Texture Cleanup, Crash Unwinding & Launcher Guards:** Added front-end UI texture cleanup in `d3d9_texture_healer.cpp` to help reduce D3D9 slot pressure during longer sessions; improved `veh_crash_shield.cpp` benign exception filtering and chained `.pdata` (`UNW_FLAG_CHAININFO`) unwind resolution; sharded `textures.s2z` into two `< 1.50 GiB` non-Zip64 archives; tightened `WILLOWMAKER` bundle-root/process checks, live manual freeze minidump scoping (`clientRoot` + `expectedProcessId`), Safe Mode recovery, and diagnostic redaction (including Windows CRLF hardware MAC scrubbing); and unified shared `NpgsqlDataSource` pooling.

## [5.0.1] — Queue Arcade, Custom Maps, Friendslist Broadcasting & Turnkey Docker

> 📖 Full player & operator notes: [`docs/releases/v5-update-notes.md`](docs/releases/v5-update-notes.md) • [`docs/releases/whats-new-in-v5.md`](docs/releases/whats-new-in-v5.md)

### Added
- **Queue Arcade ("While You Wait" Skirmish Matches):** Drop into isolated bot skirmish lobbies while waiting in matchmaking queue, with `/arcade` toggles, live countdown banner, and automatic 3-second pre-lobby handoff.
- **Spectating, Mentoring & Friendslist Broadcasting:** End-to-end Spectate/Mentor requests, live friendslist status broadcasting (Online, AFK/DND, Lobby/Queue, In Match), Monitor Game, and right-click lobby invites.
- **Expanded Playable Map & Bot Roster:** 20-player (`10v10`) Chaos modes (`Devo Wars`, `Mid Wars`, `True Devo Wars`), classic/multi-lane maps (`Three Kingdoms`, `Persian Pass`, `Grimm's Crossing`, `Darkwood Vale`, `Watchtower`), sports/duels (`Strikers 5v5` with bots), co-op/survival (`Enfo's Team Survival`, `Nightmarish Co-Op`, `Empath Maze`), seasonal Halloween maps, and persistent Easy/Medium/Hard bot difficulty scaling across 20 bot-enabled maps.
- **Turnkey Full-Stack Docker Compose (`kongor-stack`):** One-command backend cluster + Dedicated Match Fleet (`:11334`) + Queue Arcade Fleet (`:11484`) + optional host client via `./kongor.ps1 docker up` and Control Panel **`Docker Stack`** flyout.
- **Cleanroom Governance & Public Export Pipeline:** 8-gate default-deny cleanroom export (`scripts/Invoke-PublicGithubExport.ps1`), REUSE 3.2 multi-license compliance (`AGPL-3.0-or-later`, `MPL-2.0`, `CC-BY-NC-SA-4.0`, `GPL-3.0-or-later`), and zero-LFS GitHub CI workflows.

### Changed
- **Launcher Safety & Privacy:** Added `PKV Guard` signed-manifest verification in `WILLOWMAKER`, Safe Mode crash relaunch recovery, and automatic minidump/diagnostic path scrubbing.
- **Monorepo Consolidation:** Unified native C++ proxies under `native/proxies/`, organized `scripts/` into domain tiers (`scripts/lib/`, `scripts/qa/`, `scripts/dev/`, `scripts/docker/`, `scripts/re/`, `scripts/release/`, `scripts/vfs/`, `scripts/assets/`), and consolidated documentation under Diataxis `docs/`.

## [5.0.0] — Core Platform & Engine Modernization Baseline

> 📖 Full technical overview: [`docs/releases/whats-new-in-v5.md`](docs/releases/whats-new-in-v5.md)

### Added
- **Unified .NET 11 Monorepo (`ProjectKongor.slnx`):** Consolidated `WILLOWMAKER` (Avalonia client launcher), `COMPEL` / `COMPEL.GUI` (Win32 Job Object + 1.0 ms pacer server supervisor), `NEXUS.ControlPanel.GUI` (Avalonia 11.2.3 + Three.js 3D viewer), `KONGOR.MasterServer` (SRP-6a + `MERRICK` EF Core multi-DB), `TRANSMUTANSTEIN.ChatServer` (`System.IO.Pipelines` TCP), `ZORGATH.WebPortal.API` (REST/OpenAPI/Scalar), `DAWNBRINGER.WebPortal.UI` (ASP.NET Core MVC Razor), and `.NET Aspire 13.6.5` orchestration.
- **Native Modernization Layer (`native/`):** CMake-built `version.dll` / `libk2_native_guard.so` (`NativeGuard`), `VkLayer_hon_replay_capture.dll` Vulkan 1.3 shared-memory swapchain capture, `libdeflate`-accelerated `zlibwapi` proxy, `NEXUS.SpatialAudio` FMOD Ex bridge, and `luac51` standalone bytecode compiler.
- **TAO (Together As One) MCP Server (`src/tools/kongor-cli/`):** Native JSON-RPC 2.0 MCP server with Zero-Focus-Theft Mailbox IPC (`CompositeGameIpcBridge`), sub-millisecond `.s2z` `VfsIndexService`, and autonomous command self-healing.
- **In-Game Quality-of-Life:** Unlocked `/dance` hero emotes, in-game **Options -> Mods** toggles, System Taskbar quick settings, DXVK Vulkan 1.3 rendering + 1000 FPS unlock, and `KWAL` write-ahead replay crash protection.
