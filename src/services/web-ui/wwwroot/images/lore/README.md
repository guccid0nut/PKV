# Parallel Universe Timeline — Sample Development Lore Assets

> [!NOTE]
> **Development Sample Notice (Non-Official AI-Generated Placeholders)**
>
> The `.webp` comic covers, banners, and story pages in `src/services/web-ui/wwwroot/images/lore/` are **not** official *Heroes of Newerth* comics or retail game assets.
>
> They are **AI-generated sample placeholder illustrations** included strictly for local development and UI demonstration of DAWNBRINGER's **Parallel Universe Timeline** system.

## Why This Directory Exists

In Project KONGOR V, each community-operated Master Server can host its own custom **"Parallel Universe Timeline"**—an independent narrative canon, custom comic arcs, and community-authored lore entries stored in its own database and `wwwroot/images/lore/` catalog without altering retail game files.

Server operators and community artists can:
1. Replace or remove these sample issues via the **Staff Lore Management** dashboard (`/staff/lore`) or database seed configuration.
2. Upload original community-created artwork (`.webp` / `.png`) under `arcs/` and `comics/` to publish their server's own storyline.
