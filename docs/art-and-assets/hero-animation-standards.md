## 1. Executive Overview & Empirical Baseline

This document codifies the definitive historical animation, timing, and rigging standards extracted from all 277 heroes and 469 Model Definition Files (`.mdf`) in Project Kongor. These empirical metrics serve as the strict calibration ground truth for the Phase 4 ("The Living Nexus") autonomous Hero Forge pipeline.

All newly synthesized heroes and Alt Avatars must comply with these empirical boundaries to ensure seamless integration with the K2 engine, preventing visual hitching, floating meshes, mismatched gameplay collision, or de-synced combat timings.

### 1.1 Summary of Historical Monorepo Metrics

Standard Bounding Box Attributes: boundsheight="112", boundsradius="24" (up to boundsheight="160", boundsradius="32" for heavy tanks).

| Metric / Parameter | Historical Empirical Distribution | Standard Value | Strict Engine Boundary |
| :--- | :--- | :--- | :--- |
| **Bounds Height** | Standard humanoid: boundsheight="112"; Heavy tanks: boundsheight="160" | **112.0** (standard) / **160.0** (tank) | 112 <= height <= 160 |
| **Bounds Radius** | Standard humanoid: boundsradius="24"; Heavy tanks: boundsradius="32" | **24.0** (standard) / **32.0** (tank) | 24 <= radius <= 32 |
| **Locomotion Speed** | Min: 285.0, Max: 330.0, Median: **300.0**, Mean: 298.8 | **300.0** units/s | 285.0 <= speed <= 330.0 |
| **Attack Action Point Ratio** | Min: 0.170, Max: 0.686, Median: **0.438**, Mean: **0.424** | **~0.42** (~42% windup, ~58% recovery) | 0.38 <= ratio <= 0.46 |
| **Action BlendTime** | Attacks, spells, abilities: Median **200 ms**, Mean 184.6 ms | **200 ms** | 150 <= blend <= 250 ms |

      |              |                   +-- Bip01 L Finger0 / Thumb

      |                        +-- Bip01 R Forearm

### 4.1 Calibration Invariant Enforcement in `hero_forge.py`
When generating an entity:
1. `boundsheight` must match either `112`, `128`, or `160`.
2. `boundsradius` must match either `24`, `28`, or `32`.
3. `movespeed` must reside within [285.0, 330.0] units/s.
4. `actiontime` and `duration` on `attack_1` and `attack_2` must satisfy:
   0.38 <= (actiontime / duration) <= 0.46

## 5. Continuous C1 Cyclic Boundary Hermite Smoothing

To eliminate visual hitches or snapping at the loop seam (f = N-1 -> f = 0) on looping tracks (`idle`, `walk`, `run`, `portrait`), the pipeline implements a continuous C1 cubic Hermite smoothing filter across the final K = 6 frames:

### 5.1 Formulation
For track values y[0 ... N-1], let normalized blend phase s = (f - (N - K)) / K in [0, 1] for f in [N-K, N-1].
- Start state: y0 = y[N - K], tangent v0 = (y[N - K + 1] - y[N - K - 1]) / 2.
- Target state (wrapped frame 0): y1 = y[0], tangent v1 = (y[1] - y[0]) / 1.0.
- Angular unwrapping: If y represents Euler angles, adjust y1 by +/- 360 deg such that |y1 - y0| <= 180 deg.

### 5.2 Hermite Basis Functions
- h00(s) = 2s^3 - 3s^2 + 1
- h10(s) = s^3 - 2s^2 + s
- h01(s) = -2s^3 + 3s^2
- h11(s) = s^3 - s^2

y(s) = h00(s) * y0 + h10(s) * v0 * K + h01(s) * y1 + h11(s) * v1 * K

### 5.3 Acceptance Criteria for Loop Closure
1. Rotational delta: delta_R = |y[N-1] - y[0]| < 0.01 deg.
2. Velocity delta: |v_seam - v0| < 0.05 deg/frame.
3. Zero gimbal lockout: all Euler angles clamped within [-90 deg, +90 deg].
